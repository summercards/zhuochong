## 二、坐标约定（写代码前必读）

```
        +Z  上
         │
         │
         └────── +X  角色左手侧
        ╱
      +Y  角色背后
```

| 轴 | 含义 |
|---|---|
| `+X` | 角色**左**手侧（`left`） |
| `+Y` | 角色**背后**（`behind`） |
| `+Z` | 上 |
| 朝向 | **面朝 −Y** |

- 地面 `z = 0`。角色脚底贴 `z = 0`。
- 根骨骼名 `root`。位移型动画（Death/Revive/Knockdown…）的 `root_motion_m` 是 `[x, y]`
  **平面**位移，单位米，**写在世界 XY 平面上**，不含 Z。
- Godot 侧模型挂进场景后需绕 **Y 轴 −90°** 才能让 −Y 朝向对齐 Godot 的 −Z 前向。
  （Godot 前向 = −Z；本角色前向 = −Y ⟹ 需要 −90° 偏航。）

## 四、已知问题（上游遗留，未修）

`Jacket_Hem`（960 tri）与 `Jacket_Hem_Line`（256 tri）这两个网格**没有被蒙皮** ——
它们挂在节点上、不受骨骼驱动。表现为：角色跑动/倒地时外套下摆**不跟随**身体。

影响：视觉瑕疵，不影响功能。想修的话在 Blender 里给这两个网格补 `shin`/`thigh` 权重重导即可。
