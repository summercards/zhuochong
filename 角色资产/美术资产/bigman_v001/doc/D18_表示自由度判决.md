## §1 这条自由度为什么是「零代价」的

门禁 `no_teleport`（`anim_lib.py:569–581`）量的是

```python
record["euler"] = {name: tuple(math.degrees(v) for v in pose_bone.rotation_euler) ...}
```

即 **`pose_bone.rotation_euler` 本体**（`anim_lib.py:517–520`，`rotation_mode = "XYZ"`，
逐帧采样）。它**不是**世界姿态。

而同一个 3×3 旋转矩阵有大量等价欧拉写法：

| 自由度 | 说明 | 是否保矩阵 |
|---|---|---|
| **换支** | `XYZ` 序下每个矩阵有 **2** 组解 | ✅ 逐位相同 |
| **±360 缠绕** | `Rz(z−360k)·Ry(y−360m)·Rx(x−360n)`，`k,m,n` 各自独立整数 | ✅ 逐位相同（每个因子是独立旋转矩阵） |

保矩阵 ⟹ 世界姿态不变 ⟹ 其他**所有世界空间判据**（`rise_reach_ok` / `foot_slide` /
`sole_ground_ok` / `hand_off_ok` / `end_matches_idle_ok` / `seam_in_ok` …）一个都不动。
**所以这是唯一一条「零代价」的路。本文件把它算到底。**

## §3 判决：收益 = 0.000°

`animations/_d18_repr_dp.py`（纯离线，不 import bpy）对被测序列做的精确求解：

- **bottleneck DP**：`dp[f][c] = min_p max(dp[f−1][p], step(p,c))`，`dp[0][*]=0`；
  下界 `= min_c dp[N−1][c]`。**精确，非二分近似。**
- 候选集：每帧 **250** 个等价写法（2 支 × 5³ 缠绕，`span=1` ⟹ 每角 ±360）。
- 每根骨**互相独立**（改一根骨的写法不动别根的读数）⟹ 全局下界 `= max over 骨`。

### §3.1 结果（输入 = 门禁 samples，38 帧，50 骨，共 37 个相邻对）

```
BASELINE 复算 max_step = 28.558 @ (25, 'foot.R')      ← 与门禁逐位一致（管线自检通过）

=== 单骨下界 Top 8 ===
  foot.R         T_min =  28.558      hand.L         T_min =  24.329
  shin.R         T_min =  28.437      thigh.R        T_min =  17.556
  forearm.R      T_min =  28.025      foot.L         T_min =  15.798
  thigh.L        T_min =  26.577      upperarm.R     T_min =  14.387
  hand.R         T_min =  26.472
  forearm.L      T_min =  25.177

全局下界 T* = 28.558   （位于 foot.R）
下界仍 > 25 的骨数：6 / 50
```

**`T* = 28.558 = 基线`。一条自由度都没换来。**

### §3.2 为什么这是「无懈可击」的（不依赖 DP 正确性）

对**每一个**超限骨对，用 `span=2`（每角 ±720，**250×250 = 62 500 种组合**）暴力取最小：

| 骨 | 帧 | 现值 | 该对最小可能值 | 倍数 |
|---|---|---|---|---|
| `foot.R` | 25 | 28.558 | **28.558** | ×1.000 |
| `shin.R` | 25 | 25.348 | **25.348** | ×1.000 |
| `forearm.R` | 31 | 28.025 | **28.025** | ×1.000 |
| `thigh.L` | 22 | 26.577 | **26.577** | ×1.000 |
| `hand.R` | 18 | 26.472 | **26.472** | ×1.000 |
| `forearm.L` | 18 | 22.063 | **22.063** | ×1.000 |

6 万多种写法**一个不落**地都比不过现值。承载全局峰值的 `foot.R@f25` **根本不可能被压低**
⟹ `T* ≥ 28.558`；而原写法自身可行 ⟹ `T* ≤ 28.558` ⟹ `T* = 28.558`。
**这个结论不依赖 DP 是否写对，是纯粹的对逐对暴力最小值。**

> 候选集**非退化**（每帧 250 个，不是退化成 1 个）⟹ 「没收益」不是因为没找。

### §3.3 顺带一个实现层面的推论

`probe_d18_euler_all.py` 的 54.597 vs 门禁的 28.558 说明：**模块的后处理会整体改写欧拉写法**。
所以就算硬手写一组更优的写法落进脚本，也会在 `build_action` 阶段被覆盖掉。
**这条路在「收益为 0」之外，还有第二重死因：落不住。**

## §4 更正另一实例 `probe_d18_phi.py` 的「表示可救」判定

`probe_d18_phi.py` 的 `_best_step()` 枚举的是 `_branches(_twist(rot, φ))` ——
**先绕骨轴滚转 φ，再换支**。它得到 `f24 shin.R now=34.075 best=10.903「表示可救」`。

问题：**绕自身轴滚转 φ 不是表示自由度，是改姿态。**
骨轴方向（Y）虽然不动，但**后代骨的世界朝向会整体转 φ**；
要保住世界姿态，后代必须反向补偿 —— 而探针**没有建这个耦合**，
它把每根骨的 φ 当独立变量在优化。

⟹ 它的 `best` 是「**允许改姿态**」下的乐观下界，**不能**当成「免改落地」。
而本文件 §3 已经用「**真·零代价**」的候选集（不含 twist）证明：真·零代价的收益 = 0。

结论上两者不矛盾：**该降的幅度确实存在，但要靠改姿态或改时间轴去拿，不是靠改写法。**

## §6 唯一出路：**路径保持重采样**（path-preserving resample）

### §6.1 为什么不能靠「挪相位键」

`doc/D18_速度门禁诊断.md` §10 已实测证伪：相位常量是**姿态耦合**的
（`PELVIS_Z_KEYS / PELVIS_Y_KEYS / PLANT_KEYS / TUCK_ANKLE / HEEL_LIFT_KEYS`
全部由 `START/LEGS_DOWN/PLANT/CHEST_UP/HAND_OFF/TUCK/FOOT_SET/RISE_MID/STAND/END` 构造）
⟹ 挪帧数**同时挪世界目标姿态**。实测：42 帧 → 35.882，46 帧 → 48.055，59 帧等比 → 64.989，**全部更差**。
本支累计 130+ 组相位键实验、0 绿。**这条路已穷尽。**

### §6.2 正确做法

1. 用 §2.3 里那份**已落盘**的门禁姿态序列（38 帧 × 50 骨）当**唯一真源**：
   它是「门禁看得到的那份欧拉」，且已被双点校验证明可信。
2. 构造**单调映射** `g : [0, N−1] → [0, 37]`，`g(0)=0`、`g(N−1)=37`。
3. 在**整数新帧**上对**每一根骨**做**局部旋转插值**（方向空间 slerp），
   **不重新解 IK、不动任何世界目标**。
4. 分支连续性用 `_d18_repr_dp.py` 的候选集机制保证（每帧从 250 个等价写法里挑
   **与前一帧步长最小**的那个），否则 `to_euler()` 会跳支、制造假尖峰。
5. 首末帧**必须逐位**：`g(0)=0` → 首帧逐位 = `Knockdown_B@20`；`g(N−1)=37` → 末帧逐位 = `Idle_01@0`。

### §6.3 `N` 怎么取（**这是预测，不是结论**）

保路径时每根骨的每步角量按 `k=(N−1)/37` 线性缩小 ⟹

| N | k | 预测峰值 `28.558/k` | 余量 |
|---|---|---|---|
| 44 | 1.16216 | 24.57 | 1.7%（硬下界） |
| **46** | **1.21622** | **23.48** | **6.1%（推荐）** |

- `N_min = ceil(37 × 1.14232 + 1) = 44`。
- **推荐 N = 46**：给 slerp 非线性留余量。
- ⚠️ **这是从实测步长推出的预测，不是门禁结论。必须用一次真实门禁测量收口**
  （清单 §6：「结论必须来自渲染/门禁实测，不是公式」）。

### §6.4 为什么保路径重采样是安全的（世界空间判据逐位不动）

`rise_reach_ok` / `rise_monotone_ok` / `foot_slide` / `sole_ground_ok` / `foot_takeover_ok` /
`hand_off_ok` / `chest_rise_ok` / `end_matches_idle_ok` / `seam_in_ok` 全部是**世界空间**度量，
路径不动它们就不动。且拉长时间轴使动作**更慢** ⟹ 与 §6 硬约束
「慢起手、极重命中、惯性、不许急停」**同向**，不冲突。
末 6 帧「增量单调收敛」（`no_snap_stop_ok`）也保持（重采样保单调）。
