# BIGMANFIGHT 格斗动画生产链 —— 常驻指令（正本）

> **本文件是定时任务的正本指令。**
> 定时任务里只写一句话：「读取并严格执行 `doc/动画生产定时任务.md` 的全部指令。」
> 改流程只改本文件，不用动定时任务本身。
>
> **调度方式**：不是周期任务，而是**一次性 + 自链接**——每次运行的最后一步，把自己再安排到
> 3 分钟后。做完一支自动接下一支，连续生产。周期任务的粒度只到「小时」，
> 写不出「每 40 分钟」，所以不用周期任务。

角色目录：`I:\工作项目\BIGMANFIGHT\角色资产\美术资产\bigman_v001`

---

## 0. 开工

1. 读 `doc/动画制作清单.md`，取**第一个**状态为「⬜ 待做」的条目（文件顺序就是制作顺序 A→B→C→D→E）。**清单是唯一排产表。** 一次只做这一条。
2. 读 `doc/rig_axis_map.md` 确认骨骼轴向语义（57 骨 FK，欧拉 XYZ）。
3. 读 `animations/anim_lib.py`（姿态/打帧/命中停顿/测量/门禁/渲染/导出工具）与
   `animations/anim_idle_01.py`（已完成的 A01，作为写法样板）。
4. 清单「制作日志」里若已给出本条的详细制作计划，按计划执行。

## 1. 制作

- 新建 `animations/anim_<id小写>.py`，逐条落实清单里该条的设计制作要求。
- 为该动画写**专属门禁**：把清单里的文字要求翻成可量化判据
  （例：「动作幅度大」→ 攻击帧手部世界行程 ≥ 400 mm；「命中停顿」→ 停顿 ≥ 2 帧）。
- 关键姿态必须**渲染出图看**再定，不要只信数值推导。

## 2. 验证（离线跑，不需要 BlenderMCP 桥）

在 `animations` 目录下执行：

```
"D:/Program Files/Blender Foundation/Blender 4.5/blender.exe" --background --factory-startup --python anim_<id>.py
```

门禁全绿（报告里 `failed=[]`）才算完成。红了就改参数重跑，**禁止放宽容差来凑绿**。

## 3. 出图

- 关键帧静帧、多视角 → `previews/anim/`（用 `A.render_pose_sheet`）
- 动态预览：`ANIM=<id> VIEW=side` 运行 `render_mp4.py` 出 mp4
- 用 `verify_glb.py` 确认新动画已进入 `bigman_anim_v001.glb`

## 4. 收尾

- 更新 `doc/动画制作清单.md`：该条状态改「✅ 已完成」、更新进度统计与「下一支」，
  并在「制作日志」追加一条（做了什么 / 关键数值 / 门禁结果 / 遗留问题 /
  **下一支动画的详细制作计划**）。
- 在 `.workbuddy/memory/YYYY-MM-DD.md` 记录当天工作。
- 用中文向主人汇报：这支做了什么、门禁数值、还差什么、下一支是什么。

## 5. 接棒（**必须执行，放在本轮最后**）

1. 若清单里已无「⬜ 待做」项 → **不再接棒**，在汇报里说明全部完成并请主人确认是否扩充清单。
2. 否则取时间（**禁止自己心算时间**）：
   ```
   date -d '+3 minutes' '+%Y-%m-%dT%H:%M'
   ```
3. 调 `automation_update` 安排下一棒：

   | 字段 | 值 |
   |---|---|
   | mode | `create` |
   | name | `BIGMANFIGHT 格斗动画生产链` |
   | scheduleType | `once` |
   | scheduledAt | 上一步的时间 |
   | status | `ACTIVE` |
   | cwds | `I:/工作项目/BIGMANFIGHT` |
   | prompt | `读取并严格执行 I:\工作项目\BIGMANFIGHT\角色资产\美术资产\bigman_v001\doc\动画生产定时任务.md 的全部指令。` |

4. **即使制作中途失败，也要先接棒再汇报失败**——链断了就没有下一棒了。
   同一支连续失败 3 次，在汇报里显著标注，仍然接棒。

## 6. 硬性约束（违反即返工）

- **绝不写回 `bigman_tpose_v001.blend`**（角色定稿文件）；动画只落在
  `bigman_anim_v001.blend` / `bigman_anim_v001.glb`。
- 力量传导链 **脚→腿→髋→腰→肩→手**，每段都要有关键帧，禁止「只有手在动」。
- 攻击动画必须显式拆分 **前摇 / 命中帧 / 后摇 / 可取消帧**，并在 Action 上用帧标记标出。
- 启动略慢、命中极重、动作有惯性、收招不能瞬停；命中关键帧做 **2~4 帧完全停顿**。
- 动作幅度要大、要夸张、要有力道 —— 这是格斗动画，不是日常动作。
- 站姿类动画脚不许滑动（≤3 mm）；支撑脚鞋底贴地（−2 ~ +6 mm）。
- 尺寸与姿态结论一律以**渲染实测与门禁数值**为准，不要凭公式推断。
- 循环动画首尾姿态必须**逐位一致**（用同一组参数生成）。
- 单支目标耗时 ≤ 40 分钟（含渲染与验证）。若明显超出，可把次要项记为遗留问题，
  但**门禁不许放宽**。
